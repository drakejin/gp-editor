# Korean glossary (한국어 용어집)

The Korean catalogue (`ko/`) uses these words, and only these, for these ideas. Add a row before using a new term in
more than one place. Guitar terms are the ones Korean guitarists say (lesson books, 기타 커뮤니티, 타브 악보 사이트),
not dictionary translations; engraving terms follow 음악 교과서 usage.

## Style

- Menu items, buttons and tab names: short noun forms — `저장`, `다른 이름으로 저장…`, `닫기`, `적용`. Keep `…` where the
  English has it (a panel or a question follows), as macOS's Korean menus do.
- Sentences (hints, notes, errors): polite formal `~합니다 / ~습니다`; what the user should do: `~하세요`.
  Never `~해요`, never `~하십시오`.
- Tooltips: what the control does, as a noun phrase or a short sentence (`마디 삭제`, `커서 뒤에 박을 넣습니다 (I)`).
- Keys stay as macOS writes them: `⌘`, `⇧`, `⌥`, `⌃`, `⌫`, `↩`, `Esc`, `Space` → `스페이스`.
- Numbers come before Korean counters without a space: `3마디`, `4박`, `2반음`; ordinal positions: `마디 3`, `1번 줄`,
  `트랙 2`, `성부 1`. Counted things that have no counter take `개`: `음표 5개`, `트랙 3개`.
- Particles after a placeholder whose last sound is unknown use both forms: `{name}(을)를`, `{name}(이)가`, or the
  sentence is turned so no particle follows the placeholder (preferred: `“{name}”의 변경 사항을 저장할까요?`).
- Quotation marks: `“…”` as in the English.

## What stays as it is

- On the score and on palette buttons that copy a score mark: technique abbreviations (`P.M.`, `L.R.`, `H/P`, `let ring`,
  `N.H.`, `A.H.`, `T.H.`, `P.H.`, `S.H.`, `rasg.`, `Ped.`, `8va`, `8vb`, `15ma`, `15mb`, `loco`), dynamics (`ppp`–`fff`,
  `cresc.`), directions (`D.S. al Coda`, `Fine`, `To Coda`, `Segno`, `Coda`), note names (`C`, `F♯`, `B♭`), chord names
  (`Cm7`, `G/B`), tuning names written with note names (`E A D G B E`, `Drop D`).
- File formats and products: `Guitar Pro`, `GP5`, `.gp`, `MusicXML`, `MIDI`, `PDF`, `PNG`, `WAV`, `AIFF`, `FLAC`, `MP3`,
  `Ogg Vorbis`, `SoundFont`, `Claude`, `Anthropic`, `Finder`, `macOS`.
- Units: `BPM`, `Hz`, `dB`, `kbps`, `dpi`, `ms`, `%`.
